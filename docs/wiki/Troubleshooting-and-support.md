# Troubleshooting and support

| Symptom | First check |
| --- | --- |
| No species, careers or references appear | The selected-book filter may be empty or exclude those sources. Check Owned books. |
| A new feature is missing | Compare the installed system version with Releases. Wiki candidate features may not be published yet. |
| A player cannot see a map or actor | Check scene visibility and document ownership from a separate player login. GM visibility is not player visibility. |
| Shared changes are waiting | In the gameplay candidate, confirm the intended GM tab as Transaction authority; reselect after reload. |
| A talent has no automatic effect | Read Help & rules coverage and the cited book. Verified topology is not complete effect automation. |
| A vehicle lacks weapons or statistics | Its source profile may still be incomplete or awaiting printed-page review. Do not assume placeholder values are authoritative. |
| Remembered books are missing | Use the same browser profile and Foundry address. Private browsing or cleared site data can remove the local preference. World books are saved separately. |
| A book save is refused after another GM's edit | Reopen setup and review the current bookshelf. |
| Low frame rate | Disable cosmetic altitude shadows/target animation, check optional modules, and test in a separate module-free world. |

For an issue, record the installed Foundry/system/module versions and a short repeatable sequence. In the gameplay candidate, Help & rules coverage offers an inspectable diagnostic JSON containing allow-listed versions, integration states and counts. It excludes actor names, chat, private notes, settings and credentials, and does not upload itself.

Report normal defects through [Issues](https://github.com/Hill-To-Die-On/Star-wars-FFG-game-system/issues). Use GitHub's private vulnerability reporting for a security issue; do not post exploit details or secrets publicly.

Back up the complete world and private assets before upgrading. Stop writes for the backup and test restoration in an isolated world. A successful ZIP build or unit suite does not replace a restore test or a real table session.
