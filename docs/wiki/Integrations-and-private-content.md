# Integrations and private content

## Dice So Nice

Dice So Nice is optional. It animates the system's seven narrative dice while the native roll and chat result remain authoritative. Test sheets and ordinary chat before introducing optional modules.

## Director of Realms

DoR is optional; the system can be played with a human GM. DoR provides adventure-PDF import and AI-assisted campaign tooling. PDF import is not supplied by this system alone.

The integration exposes structured actor, dice and supported rules context. Unsupported mechanics must request a GM ruling. A successful native roll or source lookup does not establish that an entire AI-led campaign has passed acceptance. Full beginner and mixed-rule campaign validation remains open.

Review provider configuration, costs and what private campaign material a provider may receive. Private source-note encryption and local storage do not automatically make every downstream AI request private.

## Public integration API

Versioned imports can carry characters, adversaries, vehicles, groups and community rules. Review the proposed documents and any replacement choices before accepting. Exact-origin controls and Foundry permissions still apply; a connected website does not receive unrestricted GM authority.

Use the repository's public API documentation and schemas for the installed system version. Never place API keys or private source text in a public handoff URL.

## Local libraries and source notes

The system includes the creator-authorized reference catalogue. Private libraries are optional. Local imports can contain richer personal reference material, but they must remain within the table's lawful use and permission boundaries.

Export the GM source key before clearing browser data or moving to another browser. Keep that key private and backed up separately. Do not attach PDFs, scans, keys or extracted prose to public bug reports.

## Candidate actor-group imports

PR #15 adds version-three actor-group packages to the unreleased candidate. A GM reviews a batch of actors with stable authored nodes and directional relationships; imported actors retain the graph provenance for connected tools. Version-one character and version-two actor imports remain supported. This does not invent relationship strength or claim live Director of Realms acceptance. See [the integration API](https://github.com/Hill-To-Die-On/Star-wars-FFG-game-system/blob/dev/docs/integration-api.md) for the contract.
