# Vehicle source coverage

The public vehicle overlay contains only numeric mechanics and book/page references. Local XML descriptions, artwork and filesystem paths are excluded.

312 of 399 database vehicles have a verified complete stat profile. 87 remain incomplete, including 2 records with conflicting structured profiles that require a printed-page check.

The complete profiles comprise 221 exact structured matches, 55 reviewed aliases and 36 profiles checked directly against held printed pages. The unresolved set comprises 84 missing profiles, 2 conflicts and 1 partial printed profile.
