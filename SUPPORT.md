# Support

The repository's issue forms route requests to the information needed for a useful response:

- use **Installation or usage help** when Foundry setup or a workflow is unclear;
- use **Bug report** for reproducible incorrect behaviour;
- use **Rules or reference data correction** for source-reference, talent-tree, signature-ability, vehicle, or automation gaps;
- use **Feature request** for new behaviour.

Before filing, use the latest Star Wars FFG release and record the Foundry version, active modules, campaign rule lines, and browser or desktop client. For a defect, test with unrelated modules disabled where practical and include the smallest useful console excerpt.

The public system is an implementation and reference index. It does not replace the rulebooks and cannot provide copied rules or adventure text. Cite a book and page instead. Remove credentials, player data, campaign notes, PDFs, scans, and other private material from logs and screenshots.

Security reports must use the private route in [SECURITY.md](SECURITY.md). General documentation begins in [README.md](README.md), with focused guides under [`docs`](docs).
